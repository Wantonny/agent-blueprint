TOQOO — AGENT BLUEPRINT

Cara membuka:
1. Ekstrak seluruh isi ZIP ke satu folder.
2. Buka index.html menggunakan Chrome, Edge, atau browser lainnya.
3. Gunakan navigasi, tab agen, funnel, dan rencana 30 hari.

Checklist disimpan pada browser/perangkat yang digunakan jika penyimpanan browser tersedia.
Font online memerlukan internet; font bawaan tetap dipakai jika internet tidak tersedia.
blueprint.md berisi laporan sumber yang dapat dibuka dengan editor teks.

Website ini adalah presentasi strategi interaktif, belum menjalankan agen AI atau terhubung ke CRM.
Publikasi online belum berhasil karena server repositori tidak dapat diakses dari lingkungan pengerjaan.
